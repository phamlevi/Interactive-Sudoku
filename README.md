Open the project folder on your IDE terminal </br>
Run `npm install` if you don't have the package installed on your machine </br>
Run `npm run dev` to start the development server </br>
Ctrl+Click on the localhost link to open the game on a web browser </br>
</br>
To play on your mobile device: </br>
Ensure that your PC and model device are connected to the same network </br>
Run `npm run dev` to start the development server </br>
Run the `ipconfig` command in your PC terminal </br>
Under the Wireless LAN adapter Wi-Fi section, there will be the IPv4 Address </br>
Then type in the IPv4 Address on your phone browser, and after the IP address type the port address </br>
&nbsp; EX: localhost:3000/ </br>
Then :3000 is your port address in this case </br>
